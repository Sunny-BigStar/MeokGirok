# MeokGirok (먹기록)

식품 영양성분표나 음식 사진을 찍으면 Claude가 칼로리·영양소를 읽어 기록하고, 하루 권장량 대비 달성률을 자동으로 계산해 주는 식단 기록 서비스.

## 기능
- 📷 사진 분석: 영양성분표(라벨)는 인쇄된 값을 읽고, 음식 사진은 1인분 양을 추정
- 분석 결과를 저장 전에 확인·수정 (여러 음식이면 선택, 섭취량 배수 조절)
- 내 정보(성별/나이/키/몸무게/활동량/목표) → Mifflin-St Jeor 공식으로 권장 칼로리와 탄단지·당류·식이섬유·나트륨 기준 계산
- 하루 달성률(링 + 영양소별 막대), 날짜 이동, 최근 7일 칼로리 그래프
- 끼니 구분(아침/점심/저녁/간식, 시간대로 자동 선택)과 끼니별 칼로리 합계
- 자주 먹는 음식(최근 30일 빈도순) 탭 한 번으로 재기록
- 기록 수정(목록에서 항목 탭), 섭취량 빠른 선택(×0.5~×2, 라벨에 총 제공 횟수가 있으면 "전체")
- 주간 리포트(기록한 날 평균, 탄단지 비율, 권장량 ±10% 달성일, 부족/과다 영양소 안내)
- 체중 기록과 추이 그래프 — 최신 체중으로 권장량 자동 재계산
- AI 결과가 틀리면 "밥은 반 공기"처럼 설명을 적어 다시 분석
- AI 결과 자동 검증: 범위를 벗어난 값 보정, 칼로리와 탄·단·지가 안 맞으면 화면에 경고
- 선택형 비밀번호 보호(`APP_PASSWORD`), 오프라인에서도 화면이 열리는 서비스 워커
- 전체 기록 CSV 내보내기(`/api/export.csv`, 엑셀 호환)
- 직접 입력, 홈 화면에 설치 가능한 PWA 매니페스트

## 실행
```bash
npm install
cp .env.example .env   # ANTHROPIC_API_KEY 입력
npm start              # http://localhost:3000
npm run start:mock     # API 키 없이 가짜 분석 결과로 UI 확인
npm test
```
휴대폰에서 쓰려면 같은 네트워크에서 `http://<PC IP>:3000` 으로 접속하세요(카메라 촬영 가능).

## 구조
- `src/app.js` Express API(`server.js`는 실행 진입점) · `src/analyze.js` Claude 비전 분석(구조화 출력) · `src/nutrition.js` 권장량 계산 · `src/store.js` JSON 파일 저장(`data/`, git 제외)
- `public/` 모바일 우선 웹 UI (프레임워크 없음)

## 주의
- `/api/analyze`는 유료 API를 호출하므로 IP당 10분에 20회로 제한됩니다(`ANALYZE_LIMIT`로 조정).
- 기본값은 인증 없음입니다. 집 밖/공용 네트워크에서 쓰려면 `.env`에 `APP_PASSWORD`를 설정하세요(HttpOnly 쿠키, 로그인 5회 실패 시 10분 잠금). 인터넷에 직접 노출할 때는 HTTPS 리버스 프록시를 함께 쓰세요.
- 서비스 워커는 화면 파일만 캐시하고 식단 데이터는 캐시하지 않습니다. 오프라인에서는 기록 조회/입력이 되지 않습니다.
- `data/db.json`이 손상되면 `db.json.corrupt-<시각>`으로 백업하고 빈 상태로 시작합니다.
- 이 저장소는 Public입니다. `.env`와 `data/`는 커밋되지 않도록 설정되어 있습니다.
- 권장량·AI 추정값은 참고용이며 의학적 조언이 아닙니다.
